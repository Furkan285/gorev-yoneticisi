# Görev Yönetim Paneli (React + TypeScript + Tailwind CSS)

Bu proje, modern web geliştirme yönergesi kapsamında geliştirilmiş bir CRUD (Ekleme, Listeleme, Güncelleme, Silme) uygulamasıdır.

## Özellikler
- **Ekleme:** Başlık ve kategori seçimi ile yeni görev ekleme
- **Listeleme:** Eklenen görevleri tarih ve kategori etiketleriyle görüntüleme
- **Güncelleme:** Görev başlığını düzenleme ve tamamlandı olarak işaretleme
- **Silme:** İstenmeyen görevleri listeden kaldırma
- **Kalıcı Hafıza:** Tüm veriler tarayıcının `LocalStorage` alanında saklanır.

## Kurulum ve Çalıştırma
```bash
npm install
npm run dev
```
